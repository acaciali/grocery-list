# Recipe Clipper

A Chrome extension that scrapes the recipe off the page you're on and saves it.

## Adding it to Chrome

1. Open `chrome://extensions` (paste it in the address bar).
2. Turn on **Developer mode**, top right.
3. Click **Load unpacked** and select this `recipe-clipper` folder — the one with
   `manifest.json` in it.
4. Pin it to the toolbar via the puzzle-piece icon.

Then open a recipe page and click the 🧑‍🍳 chef icon.

After editing code, reopen the popup to pick up changes. If you changed
`manifest.json`, hit the ↻ button on the extension's card instead.
